# Sistema-de-gesti-n-POO
Sistema de gestión de inventario desarrollado en Python con PySide6, SQLAlchemy y SQLite, aplicando POO, arquitectura en capas y separación entre el dominio, la GUI y el acceso a datos. Incluye autenticación segura, gestión de inventario, generación y exportación de reportes en Excel y PDF, y soporte para etiquetas con códigos de barras.
